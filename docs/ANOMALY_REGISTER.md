## Known baseline capture differences

The harness never touches the network, so the baseline differs from the live site in known ways. These are not Sova defects.

- **Fonts:** `fonts.googleapis.com`, `fonts.gstatic.com`, `fonts.cdnfonts.com` and `use.fontawesome.com` are blocked, so shots use fallback fonts and Font Awesome icons are absent. Sova uses system fonts anyway; compare layout, not glyph shapes.
- **GSAP:** loaded by the source from cdnjs; served from the mirror's identical 3.12.2 copy in the "Save Page" folder (logged as `local`; every other non-source host is aborted). Timelines are jumped to their end state and paused, ScrollTriggers disabled in place.
- **Not in the mirror (404, logged as `missing`):** Flatsome `chunk.slider.js`, `chunk.popups.js`, `chunk.tooltips.js`, `chunk.countup.js` (Flickity sliders stay un-initialised, count-ups show their static value), some `wp-content/uploads` SVG/WebP decorations and contact-button icons, the `moul` web font, `wp-json`/`admin-ajax` endpoints, and all `wp-admin/css|js` (the login page `login-vi` renders without WordPress login styles).
- **Slick** (`cdn.jsdelivr.net`, About pages) and third-party scripts/embeds (GTM, Facebook, TikTok, YouTube, maps) are blocked.
- **Project grid AJAX:** `/du-an/` and `/en/our-project/` load their cards by POST to `wp-admin/admin-ajax.php` (`load_portfolio_items`). Offline it is 404, so the baseline shows the "Đang tải..." placeholder instead of cards. The card markup is available statically in `featured_item_category/*/index.html` (what `serve.py` stitched together); epic-collections compares the grid against those pages, not this baseline.
- **Page wider than viewport:** 75 of 312 shots are wider than their viewport (e.g. `home-vi/390.png` is 464 px, About at 550 is 565–594 px) because the source overflows horizontally; full-page shots include the overflow. This is source behaviour, kept as evidence for the epic-fidelity-and-handoff overflow sweep.
