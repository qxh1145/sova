## 4. Công việc chuyển tiếp Phase B (Phase B work)

Theo [docs/MIGRATION_PLAN.md:111-120](MIGRATION_PLAN.md#L111-L120), Phase B tập trung tích hợp backend và hệ thống quản trị sau khi UI mock hoàn tất:

1. **API repository & Seed data**: Xây dựng API repository / validation schema và import mock seed data; không làm thay đổi hệ thống phân cấp component đã hoàn thiện ở Phase A.
2. **Admin modules**: Triển khai các module quản trị theo [docs/ADMIN_CONTENT_MAP.md](ADMIN_CONTENT_MAP.md): quản lý collections, structured page editors, shared content, site settings, navigation, media; không xây dựng page builder tự do.
3. **Auth & Roles**: Xây dựng luồng xác thực và phân quyền riêng cho admin; URL đăng nhập legacy (`/login-eras/`) chỉ là utility snapshot và không tự động trở thành auth dashboard.
4. **Publish workflow & Cache**: Kết nối quy trình draft, publish, preview, upload media, quản lý lịch sử slug, bảo đảm tính nhất quán dữ liệu và cơ chế xóa cache (cache invalidation) cho mọi consumer dùng shared records.
5. **Form delivery & Integration tests**: Kết nối dịch vụ gửi form và captcha theo giải pháp backend được lựa chọn; chỉ khẳng định gửi thành công khi có phản hồi live-success thực tế. Chạy integration tests cho API, quyền hạn và submit form tại Phase B (không biến chúng thành gate của UI mock).
6. **Đối chiếu sau import**: So sánh lại toàn bộ nội dung, layout và liên kết sau khi import dữ liệu thật; số lượng bản ghi chính xác ở nguồn là baseline, không giới hạn cứng số lượng record có thể thêm từ admin.
